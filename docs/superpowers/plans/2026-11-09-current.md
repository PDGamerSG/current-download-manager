# Current Implementation Plan

> Execute inline in this empty workspace; each subsystem has its own verification gate.

**Goal:** Ship a usable native macOS download manager, browser integration, reproducible tests and a public repository.

**Architecture:** SwiftUI app and Swift CLI share CurrentCore, which drives aria2 through authenticated JSON-RPC. Browser native messaging forwards validated commands to a private loopback bridge.

**Tech Stack:** Swift 5.9 package, SwiftUI/AppKit/Network, aria2 1.37, JavaScript WebExtensions, Python standard-library integration fixtures, Node test runner.

**Spec:** `docs/superpowers/specs/2026-11-09-current-design.md`

## Global constraints

- Source deployment target: macOS 13.0. The current prebuilt arm64 artifact requires macOS 27.0 because of its installed dependency binaries.
- Original implementation and branding; never redistribute IDM.
- Restrict state to the current user's account and never export credentials.
- No Internet-facing RPC or web-page CORS access.
- Name the release architecture; distinguish ad hoc signing from notarization.
- Never claim untested browser or Windows compatibility.
