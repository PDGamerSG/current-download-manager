Connect Current to your browser

This local extension sends network URLs to the Current macOS app through the browser’s native messaging API. Automatic capture starts off.

  1. Install or build Current. Keep the app in a permanent location, such as /Applications/Current.app.
  2. Open Current’s browser settings and install the native host, or run /Applications/Current.app/Contents/MacOS/currentctl install-browser-host in Terminal.
  3. Load the extension matching your browser using the source project’s extensions/README.md instructions.
  4. Pin Current to the toolbar and open its popup. A working native connection says “Connected to the macOS app”.

Using Current

Paste a URL in the popup, use a link’s “Download with Current” context menu, or select page links and use the selection context menu. Video sources and observed media responses appear in the popup. Videos with a downloadable DOM source get a download button.

Enable “Capture browser downloads” to hand over eligible new GET downloads. Current pauses the browser copy, asks the local app to accept the URL, then cancels the browser copy after acceptance. If the app rejects or disconnects, the browser copy resumes. The popup, a red badge, and a browser notification show failures.

Open Capture settings to limit automatic capture by file extension or exclude domains and URL patterns. Empty file types allow every type. Explicit popup, media-button, and context-menu downloads still work for excluded URLs. Hold Alt (⌥ Option on Mac) while clicking a link to keep it in the browser; the bypass lasts 10 seconds in that tab.

What the extension sends

For each URL you add, Current reads cookies scoped to that destination URL and passes them to the local app with an appropriate page referer and this browser’s User-Agent. It does not upload them to an external service. Downloads retain their own URL-specific headers in the app’s private state directory. Use the app only with sites and media you are authorized to download.

Browser and media limits

Chrome, Chromium, Edge and Brave use the Chromium folder. Firefox uses its own fixed-ID extension. Firefox temporary loading is removed when Firefox restarts; ordinary Firefox requires a Mozilla-signed package for permanent installation. No signed store release is included.

POST, blob, data, completed, paused and unclassified downloads remain in the browser. Protected browser pages cannot be inspected. Browser private windows are disabled for this extension. Cookie containers, partitioned cookie sessions and unusual authentication flows may require downloading in the original browser.

Clear HLS/DASH needs the app’s optional yt-dlp and ffmpeg tools. DRM, encrypted service playback and universal website coverage are not supported. Safari needs a separate signed Safari Web Extension container and is not included in this local package.

If the connection fails

Open Current, reinstall the browser host after moving the app, and confirm the extension ID matches the generated local package. Reopen the popup after installing the host. The host permits only the exact Current extension IDs; it has no wildcard origins.
